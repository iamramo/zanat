# @iamramo/zanat-core

Core library for [Zanat](https://github.com/iamramo/zanat). This package powers the CLI, but you most likely want to install that instead:

```bash
npm install -g @iamramo/zanat-cli
```

## Usage as a Library

```bash
npm install @iamramo/zanat-core
```

Provides Git operations, skill management, configuration handling, and lock file management. See the source for available exports.
